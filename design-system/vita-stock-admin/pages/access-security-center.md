# 系统访问与安全态势中心页面级视觉基线

本文件仅覆盖 `risk-dashboard` 入口与 `/risk/dashboard` 页面。管理端系统、用户和角色页面继续使用
`MASTER.md` 的浅色管理端规则；行情大屏继续使用 `market-dashboard.md`，两套大屏不共享背景、
密度和装饰语言。

## 视觉语义

- 背景 `#031426`，面板底色 `#062a46`，悬浮面 `#0a3b60`，边框 `#1a6f91`。
- 主文字 `#e8f7ff`，次文字 `#a8c9de`，交互色 `#39e7f2`，告警 `#ff8e99`，
  警示 `#ffd37d`，正常 `#42e3c1`。
- 成功请求、来源 IP 和接口数使用青色系；失败请求、失败率和 4xx/5xx 使用红色系。
  HTTP 状态同时提供文字标签与精确计数，不只用颜色表达含义。
- 使用系统字体和 `font-variant-numeric: tabular-nums`；不加载外部字体。
- 面板保持 1px 实线边框、轻微切角和静态高光，不使用大面积霓虹、持续扫光或装饰性动画。

## 布局

- 当可用宽度至少 1440px 且高度至少 800px 时，页面单屏显示，面板悬浮在全屏地图之上。
- 桌面顶部为标题、日期、地图范围、更新时间和数据质量。六项指标横排，左右各约四分之一分别容纳排行、分类和趋势、状态、监控。中央留给地图和控件。悬浮面板使用半透明底色，详情使用更实的背景。
- 未达到单屏条件时地图独占一行。宽度达到 768px 时，图表两列排布。更窄的屏幕使用两列指标和单列图表，地图与筛选控件保留 44px 点击尺寸。
- 地图、排行、图表与页脚都允许在自身容器内滚动，不撑破整页。

## 地图

- 使用 MapLibre 本地空样式（仅背景层），不声明瓦片、字体、精灵或第三方 transform。
- 中国视图单独加载轻量世界背景和发光国界，世界交互边界打开世界视图后才加载。L7 绘制行政区填色和代表点热力，最多十二条飞线汇聚至唯一启用且已定位的地图服务器。飞线上沿来源至入口方向移动短光点，启用减弱动态效果时只显示静态飞线。
- 大屏默认 3D，顶栏可切换 2D／3D，切换保留中心和缩放。中国地图放大显示省级名称，继续放大按可见省份读取本地城市边界并显示城市名。世界地图放大显示国家与地区名称。地名随地图移动，独立于请求统计。
- 地图保持正北朝上，支持拖动平移、双指缩放与放大、缩小、复位按钮。宽屏直接滚轮缩放，紧凑窗口使用 Ctrl 或 ⌘ 加滚轮。键盘可用方向键、加减键和 0。数据刷新保留当前视角，切换范围重新适配地图。
- 行政区点选只在存在已核实编码时下钻；精确计数、未定位来源和“代表点不是实际 IP 位置”
  的说明始终可在文字明细中访问。
- WebGL 不可用、上下文丢失或底图初始化失败时使用二维 ECharts。仅立体侧面初始化失败时保留当前 L7 底图和视角中心，切回二维并显示原因。降级时保留平移、缩放和下钻。

## 数据与状态

- 指标使用当前大屏响应。QPS 显示最近入库分钟及覆盖状态，4xx 与 5xx 占比以筛选范围内总请求量为分母。迷你趋势使用实际分桶或 QPS 分钟样本。缺失数值显示 `—`，缺失列表显示空状态。
- 首次加载显示稳定状态；刷新保留上次成功结果。失败、降级、部分可用分别使用独立状态文案。
- 数据状态显示完整性、采集延迟、QPS、统计覆盖和成功／失败计数。精确时间戳和告警随详情展开。
- HTTP 状态逐码呈现条形和精确计数。请求类型环图的分母为当前已分类请求数。

## 动效与可访问性

- 非必要动画在 `prefers-reduced-motion: reduce` 下停止，地图和统计保持可用。
- 键盘焦点环清晰，图标按钮具有可访问名称；地图提供完整文字替代。
- 页面隐藏时暂停地图渲染和轮询；卸载时销毁 L7 场景、MapLibre 资源、监听器与定时器。
