# 系统访问与安全态势中心页面级视觉基线

本文件仅覆盖 `risk-dashboard` 入口与 `/risk/dashboard` 页面。管理端系统、用户和角色页面继续使用
`MASTER.md` 的浅色管理端规则；行情大屏继续使用 `market-dashboard.md`，两套大屏不共享背景、
密度和装饰语言。

## 视觉语义

- 背景 `#031426`，面板底色 `#062a46`，悬浮面 `#0a3b60`，边框 `#1a6f91`。
- 主文字 `#e8f7ff`，次文字 `#a8c9de`，交互色 `#39e7f2`，告警 `#ff8e99`，
  警示 `#ffd37d`，正常 `#42e3c1`。
- 成功请求、来源 IP 和接口数使用青色系；失败请求、失败率和 4xx/5xx 使用红色系。
  HTTP 状态同时提供文字标签与精确计数，不只用颜色表达含义。
- 使用系统字体和 `font-variant-numeric: tabular-nums`；不加载外部字体。
- 面板保持 1px 实线边框、轻微切角和静态高光，不使用大面积霓虹、持续扫光或装饰性动画。

## 布局

- 大屏占满视口，隐藏管理端侧栏；1920×1080 与 2560×1440 单屏展示。
- 桌面结构：顶栏、筛选工具栏、六项真实指标、左侧接口/来源排行、中间固定视角地图、
  右侧 HTTP 状态与趋势、底部地域/细分/数据状态、诊断页脚。
- 宽度小于 `1280px` 或可用高度小于 `720px` 时改为单列流式布局；窄屏不产生横向滚动。
- 地图、排行、图表与页脚都允许在自身容器内滚动，不撑破整页。

## 地图

- 使用 MapLibre 本地空样式（仅背景层），不声明瓦片、字体、精灵或第三方 transform。
- 使用 L7 渲染地域填色、代表点热力、来源汇聚飞线和已核实服务器终点。
- 中国和世界均固定视角，不提供拖动、缩放、旋转或倾斜；只保留中国/世界范围切换。
- 行政区点选只在存在已核实编码时下钻；精确计数、未定位来源和“代表点不是实际 IP 位置”
  的说明始终可在文字明细中访问。
- WebGL 不可用、上下文丢失或底图初始化失败时，切换到已有二维 ECharts 地图和文字排行，
  不改变统计、筛选或下钻状态。

## 数据与状态

- 只使用现有风险接口和真实响应，不新增指标。缺失数值显示 `—`，缺失列表显示明确空状态。
- 首次加载显示稳定状态；刷新保留上次成功结果。失败、降级、部分可用分别使用独立状态文案。
- HTTP 状态按 2xx、3xx、4xx、5xx、未知/其他分组，并保留逐状态精确明细。

## 动效与可访问性

- 飞线动画在 `prefers-reduced-motion: reduce` 下停止，地图和统计保持可用。
- 键盘焦点环清晰，图标按钮具有可访问名称；地图提供完整文字替代。
- 页面隐藏时暂停地图渲染和轮询；卸载时销毁 L7 场景、MapLibre 资源、监听器与定时器。
