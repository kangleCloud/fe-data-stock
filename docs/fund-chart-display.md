# 个股与大盘资金图展示规则

本次仅优化 `stockMonitor` 与市场 `overview` 的展示。V1 REST/SSE 契约、净额口径、原始元金额与采样时间均保持不变。

- 时间轴采用首末有效采样时间，左右各留 3% 间距（至少一秒）；单点前后各扩展两分钟，只绘制真实点。
- 沿用超过 180000ms 和 null 的断段规则。午休与缺样保留实际时间间隔，不补点、不压缩、不平滑。
- 按全部有效净额的最大绝对值选择纵轴单位：小于一万用元，一万至一亿以下用万元，一亿及以上用亿元。series 值仍为元；单位仅在显示时换算。
- 纵轴覆盖全部有效值与零并留边距，目标四段，刻度最多两位小数且不重复；全零仍有有效范围。
- 正净额红色、负净额绿色、零值中性，摘要与 Tooltip 保留方向符号。零线保留，隐藏图外零轴标签，以 0 刻度标识。
- 连续段隐藏常驻圆点，孤立点可见。Tooltip 限于图表内，显示真实点的完整上海日期与秒级采集时间、易读净额及完整元金额；不展示缺口内虚构值，外部字符串转义。
- 个股资金图桌面 220px、767px 及以下 200px；大盘保持 300px。个股标题展示最近有效点净额和采集时间，大盘沿用既有指标。
- 固定采样说明收纳于 Tips，支持聚焦、点击及 Escape；异常原因直接保留在正文，采样表和无数据状态保留。
- 沿用 BaseChart 实例更新及 series 替换机制，不重建实例、不重置表格滚动、不新增轮询。

## 自动验证

`tests/fund-chart.spec.ts` 使用 ECharts SVG/SSR 检查实际轴刻度，覆盖跨零、全正、全负、全零、恒定、单点、单位边界、金额和时间保真、null/长缺口断线以及 Tooltip 缺失值和转义。

`tests/fund-chart-tips.spec.ts` 验证真实 Element Plus Tips；页面与图表稳定性测试覆盖最近有效点摘要、异常状态、SSE 更新及实例、滚动和展开状态保留。

浏览器视觉与窄屏布局由用户手动验收，本次未启动预览服务或执行真实服务联调。

## 折线颜色修复

正负着色区间使用纵轴范围作为有限边界，为 ECharts 折线渐变提供正确的坐标锚点，避免渐变锚点全部重合在零轴导致负值线段误呈红色。纯零值段直接使用中性色。回归测试解析实际 SVG 的折线路径与渐变，覆盖全负、全正、双向跨零及全零线段；不只检查配置或圆点颜色。
