# 访问地图 3D 实施与验证（2026-11-04）

本次只修改前端地图渲染、依赖及其测试。`echarts-gl` 精确锁定 `2.1.0`，ECharts 保留 `^6.1.0`、Vite 保留 `^8.1.5`。[官方 2.1.0 发布说明](https://github.com/ecomfe/echarts-gl/releases/tag/2.1.0) 包含 ECharts 6 兼容修复。本机生产构建与真实 WebGL 渲染通过，无需降低全站 ECharts 版本。

## 实现

- `src/charts/risk3d.ts` 是动态导入入口，仅注册 Geo3D、Map3D、Lines3D、Scatter3D。行情 BaseChart 与通用图表注册文件未改动。
- `RiskRegionMap.vue` 继续拥有边界加载、编码校验、缓存、二维选项与地域下钻；默认 3D，可手动切到 2D。WebGL 能力失败、模块/渲染器失败或实际上下文丢失后切回 2D；不在每次刷新自动重试，可主动点击 3D 重试。
- `RiskMap3D.vue` 使用可点选的 map3D 行政区网格及同投影、同相机参数的 geo3D 弧线层。GL 层置于 -2/-1，避开 zrender 默认二维提示层 0；最终中国点选四川、世界旋转后浏览器 warn/error 日志为空。统一厚度 3，不按数量改变高度；颜色表达请求量。累计与提示复用字符串/BigInt，超过安全绘图精度时使用中性色。
- 静态弧线由有效来源代表点指向有效服务器目标，金色标记表示终点；未知来源不造点。仅在有效目标坐标设置不可见的高度范围参考点，以固定弧线比例，不增加来源或业务计数。无在线纹理、定位或新地图服务。
- 默认 alpha 35°、beta 0°、distance 160；alpha 10°～75°、distance 60～300，显式解除库内 geo3D 默认的 beta ±80° 限制。左键旋转、右键平移、滚轮缩放；聚焦后方向键、+/-、0 操作。关闭自转、过渡、特效与时间超采样。
- 相机按中国/世界保存在当前组件访问期间；刷新只更新数据，保留实时相机。拖动超过 5px 后阻止误点选。隐藏页面暂停渲染调度和数据绘图；卸载/失权/模式切换释放观察器、监听和 ECharts/GPU 实例。

## 自动验证

执行 `pnpm lint`、`pnpm test --maxWorkers=4`、`pnpm build`（含 `vue-tsc --build --force`）及 `git diff --check`。最终 64 个测试文件、450 项测试通过。一次与构建并行执行触发两项旧路由测试的 5 秒超时，限制测试工作进程后全套通过。测试覆盖模式切换、失败回退、相机缓存/边界/复位、旋转误点、精确数字、无效目标、隐藏暂停和销毁。GL 初始化异常以及库内部吞掉错误后生成的 `.ecgl-nowebgl` 层均触发回退。

## 真实浏览器证据

设备为 macOS / Chrome，实际上下文报告 `ANGLE (Apple, ANGLE Metal Renderer: Apple M4 Pro, Unspecified Version)`。使用现有冻结接口样例启动真实 Vue 大屏；横幅明确标注“3D离线样例 · 非真实联调”。上海目标为验收专用合成配置，不代表线上服务器。未将离线样例称为真实业务联调。

已实际观察：中国/世界立体网格与静态弧线；拖动旋转/倾斜，旋转后选中地域保持；键盘旋转、缩放和复位；中国 alpha 40°、beta -10° 在刷新和中外切换后保持；世界点选巴西发出 BR 下钻；中国点选发出 CN-62；键盘地域选择 CN-11 后展示北京市计数 9。世界样例的境外细分为空，其他中国省份不具备对应样例，未声称这些结果已做业务联调。右键平移已配置，尚未单独通过自动化原生右键拖动验收。

在实际地图 Canvas 上调用 `WEBGL_lose_context.loseContext()`，观察到“WebGL上下文丢失，已切回二维地图”，地图改为二维且统计仍显示；主动重试 3D 能重新创建实例。
